# AI Anime Image Manager — 软件功能说明

> 基于开源项目 **AI Image Manager v2.2.3** 的自用改造版，针对**动漫插画**做了深度优化。
> 界面图见本文件同目录的 `screenshots\anime-manager\`。

---

## 一、它是什么

一个**完全本地**的动漫图片管理器：不上传任何数据，AI 模型在你机器上跑，索引、标签、搜索全在本地完成。

**适用场景**：几万张动漫插画 / 同人图 / 画集，需要**按内容找图**、**按角色/属性归类**、**快速筛掉不想要的**。

---

## 二、继承自原版的基础功能（简述）

| 功能 | 说明 |
|---|---|
| **图像管理** | 添加任意文件夹（可多个），自动索引、生成缩略图、按目录树浏览 |
| **重复图像识别** | 感知哈希比对，找出重复/近似重复的图，支持分组查看与批量处理 |
| **以图搜图** | 用一张图去找相似的图（特征向量检索） |
| **语义搜索** | 用自然语言描述画面（如"去年秋天的红叶"）找图 |
| **收藏 / 相册 / 选片** | 标记收藏、自建相册分组、连拍选片（本版**隐藏**了相册与选片入口）|
| **日期 / 文件夹筛选** | 按时间范围、按目录快速过滤 |
| **图片预览** | 大图预览、等比缩放、EXIF 信息（本版**关闭了 EXIF**）|

> 这些是原版就有的能力，本版**基本沿用**；下面第三节之后才是本版的改造重点。

---

## 三、本版独有：标签体系（核心差异）

原版的 AI 打标是为**真人摄影**设计的 —— 153 个英文概念，套在动漫插画上产出的是噪声
（本机实测出现过「猫咪 42,632 张」这种荒唐结果）。

本版换成 **Danbooru 标签体系**（动漫圈通行的标注规范），并围绕它重建了整个标签系统。

### 3.1 AI 自动打标签

| 项 | 说明 |
|---|---|
| 模型 | **WD14 v3**（Danbooru 原生标签，10,861 个：通用 8,106 / 角色 2,751）|
| 角色标签 | 直接认出"这是哪个角色"（如 `hatsune_miku`、`ganyu_(genshin_impact)`）|
| 通用标签 | 画面内容（发色、瞳色、服装、姿势、构图…），平均 **41 个/张** |
| 速度 | **0.23 秒/张**（CPU）|
| 断点续跑 | 可随时中断，下次从断点继续 |

### 3.2 通用标签中文化

通用标签落库为 **`中文 (english)`** 格式，例如：

```
长发 (long_hair)
双马尾 (twintails)
长袖 (long_sleeves)
蝴蝶结 (bow)
```

**好处**：**中文和英文都能搜到**（英文留在括号里）。
角色标签保持英文（中文名没有可靠来源），但可以右键自己改。

### 3.3 标签树二级分类

`通用` 下面按 **13 个类型**建二级目录，不再是平铺的一大堆：

```
角色                    ← 角色标签（排在通用上面）
通用
  头发        ← hair_ornament / bow / twintails ...
  服装与配饰   ← dress / shirt / thighhighs ...
  面部与表情
  身体与特征
  人数与构图
  成人向内容
  ...共 13 类
```

### 3.4 只显示有图的标签

词表有 10,861 个标签，但**只显示你库里真正用到的**（本机实测：10,933 个标签里只有 551 个有图）。
空标签不再占据界面。

### 3.5 标签黑名单

右键标签 →「移入标签黑名单」：

- 该标签（含全部子标签）从标签树消失，**集中到面板底部的独立区域**
- 那个区域**固定在底部，不随标签树滚动**
- 左键点条目 = 按该标签筛选；右键 = 菜单里移出
- **只影响显示，不删数据** —— 照片和标签关系都在，搜索照样能找到

**用途**：不关心的分类（比如某些不想看到的类型）从视野里清掉。

### 3.6 标签重命名

右键标签 →「重命名标签」：

- **输入框只显示中文部分**，括号和英文标识不展示（避免误删）
- 保存时**自动把英文标识拼回括号里**
- 于是：**标签身份（英文）恒定**，中文和英文检索始终有效
- 清空输入 = 去掉中文名，退回纯英文

### 3.7 标签颜色

右键标签 →「标签颜色」：

- 支持 **十六进制**（`#f97316`、`f97316`、`#F97316`、`#f93`）
- 支持 **RGB**（`rgb(249,115,22)`、`RGB(255, 0, 0)`）
- 也有原生取色器和 R/G/B 三个数字输入框
- **一级标签的子树共用同一个颜色**（按一级分组的归属着色）—— 扫一眼就知道某个标签属于哪一大类

### 3.8 全库重跑

侧边栏「标签」页 → 标签树下方的「**生成 AI 标签**」按钮：

- 首次点击 = 从第 0 张开始全量重跑；之后再点 = 增量（只处理新增的图）
- **手动标签和已确认标签不会被清除**
- 可断点续跑

### 3.9 其他标签相关能力

| 功能 | 说明 |
|---|---|
| 批量打标签 | 多选照片 → 底部操作栏 → 添加标签 |
| 标签筛选 | 点标签树里的标签即按它筛选；支持多标签（与关系）|
| 中英文搜索 | 搜 `长袖` 或 `long_sleeves` 都能命中 |
| 角标显示命中原因 | 缩略图右上角显示**这张图命中了你所选标签中的哪几个**（最多 3 个）|

## 四、本版独有：删除即进应用内回收站

**原版**：删除只做软删除，**原文件不动**。
**本版**：删除 = **把原文件移动到应用回收站**。

| 项 | 说明 |
|---|---|
| 位置 | `<图库>/回收站/` |
| 命名 | `<图片ID>_<原文件名>__<删除时间戳>.扩展名` |
| 保留期 | **从删除时刻算起 30 天**，之后启动时自动清理 |
| 恢复 | 「最近删除」里恢复 → 文件**移回原位** |
| 日期不变 | **刻意不修改文件时间戳** —— 恢复后照片日期仍是原来的 |
| 安全护栏 | **移动失败就不删库记录**（避免"库里没了、文件还在原地"）|
| 清空 | 不提供"彻底删除"按钮 —— 想立刻清空**直接删那个文件夹**即可 |

## 五、本版独有：界面精简

原版功能很多，本版**隐藏了用不到的入口**（代码全部保留，可随时恢复）：

| 隐藏项 | 说明 |
|---|---|
| 数据仪表盘 | 侧边栏入口 |
| 相册 | 侧边栏入口 |
| 选片 | 侧边栏入口 |
| 云端 | 侧边栏入口 + 右键菜单里的上传/分享 |
| 序列 | 「照片/序列」切换器、序列详情、序列建议弹窗 |
| 更新提示角标 | — |
| EXIF 筛选与解析 | 顺带修掉了原版的一个日志风暴 bug |
| 6 个设置页 | 插件 / 漫游 / 序列 / 云同步 / 水印 / 更新 |
| 照片右键菜单 | 去掉了「导出」和「添加到相册」；多选时**只剩「收藏」和「删除」** |
| 搜索引导区 | 去掉了「试试这样搜索」和 4 个示例词（保留了日期快捷筛选和标签建议）|

**其他体验优化**：

| 项 | 改善 |
|---|---|
| 文件夹监听 | 原版每个子文件夹建一个监听器（本机 4,414 个）→ 本版**只监听根目录** |
| 开机增量补扫 | 关机期间存进目录的图，开机后自动补上 |
| 新图自动处理 | 软件开着时存进来的图会自动索引 + 打标 |
| 照片右键「多选」 | 右键某一格即可进入多选，之后用 Ctrl/Shift 加选 |

## 六、三个版本的区别

三个版本**同一个内核**，区别在"附加了什么能力"。

### 6.1 本地版（`AI Anime Image Manager`）—— 基线

**纯本地客户端**，上文第三～五节的功能它全都有。

- 数据全在本机，**无任何网络访问**
- 已打包 **MSI**，实测安装正常

**适合**：只在自己这台机器上用。

---

### 6.2 LAN 版（`AI Anime Image Manager LAN`）—— 独有功能：**局域网查看**

> 在本地版基础上增加"让内网其他设备也能看"的能力。

| 功能 | 说明 |
|---|---|
| **端口配置** | 设置里可指定监听端口（默认建议 47820）|
| **双口令** | **一个永久口令**（长期有效）+ **一个临时口令**（默认 24 小时，可选 1/3/6/12 小时）|
| 口令可见可改 | 设置页里**明文显示/设置**两个口令，方便发给别人 |
| **局域网检索** | 手机/平板浏览器打开 `http://<电脑IP>:<端口>` 即可搜索、浏览 |
| **保存图片** | 远程设备可下载原图 |
| **手机网页** | 独立的简洁移动端页面（不是把桌面界面搬过去）|
| **🔒 网络端只读** | 通过网络访问时**禁用删除和标签编辑** —— 而且是**服务端强制**（根本不开放写接口），不是只藏按钮 |
| 默认关闭 | 该功能默认关闭，开启时明确提示"同网段设备都能访问你的图库" |

**安全提醒**：
- 开启后**同一网段内的设备都能访问**，口令是唯一防线
- Windows 防火墙首次会弹窗，**只勾「专用网络」，不要勾「公用网络」**
- 不要暴露到公网（仅限家庭/受信网络）

**适合**：想在手机/平板上翻自己的图库，或给家人朋友看。

---

### 6.3 NEXT 版（`AI Anime Image Manager NEXT`）—— 独有功能：**识图模型更新**

> 在 LAN 版基础上**更换打标模型**，用更"见多识广"的新模型（所以局域网查看照样有）。

| 项 | 本地版（WD14）| **NEXT 版（PixAI Tagger v1.0）** |
|---|---|---|
| 词表规模 | 10,861 | **30,877** |
| 数据截止 | 较旧 | **2026 年 5 月** |
| 普通图角色命中 | 41% | 40%（持平）|
| **NSFW / 同人角色命中** | **10%** | **30%**（**3 倍**）|
| 通用标签/张 | 41 | **46.5 ~ 58.5** |
| **作品系列**（copyright）| ❌ 无 | ✅ **85% ~ 100%** |
| **内容分级**（rating）| ❌ 丢弃 | ✅ **100%**（可区分 SFW/NSFW）|
| **画风**（style）| ❌ 无 | ✅ 有（连画师风格都能认）|
| **特征维度** | 768 | **1024** |

#### 新增的三个维度价值在哪

| 新维度 | 用途 |
|---|---|
| **内容分级** | 自动区分 `rating:g/s/q/e` → 可以**只看安全内容**、可以按分级隔离、可以做筛选 |
| **作品系列** | 认出 `blue_archive` / `genshin_impact` 这类 IP → **按作品筛选**，比按单个角色更好用 |
| **画风** | 认出画师风格标签 → 按画风找图 |

#### ⚠️ NEXT 版的两个实际代价（要知道）

| 代价 | 说明 |
|---|---|
| **🔴 新模型建库明显更慢** | 单张 **0.59 秒**（本地版的 WD14 是 **0.23 秒**，慢约 **2.6 倍**）<br>**8 万张图推算约 13.1 小时**（本地版约 4 小时）<br>好消息：**可以随时中断，下次从断点继续** |
| **模型体积大 5 倍** | 1.86 GB（本地版 361 MB）→ 打包体积会变大 |

> 首次建库建议：**先放一个子文件夹试跑**，确认效果满意再对全库跑。
> 跑的时候机器可以继续用，只是 AI 处理会占一些资源。

**适合**：图库里有较多同人/原创角色、想要分级和作品筛选能力的场景。

### 6.4 三版对比速查

| 能力 | 本地版 | LAN 版 | NEXT 版 |
|---|---|---|---|
| 基础图像管理 / 去重 / 以图搜图 / 语义搜索 | ✅ | ✅ | ✅ |
| WD14 标签体系（中文/二级分类/黑名单/颜色/改名）| ✅ | ✅ | ✅ |
| 应用内回收站（30 天）| ✅ | ✅ | ✅ |
| 界面精简 | ✅ | ✅ | ✅ |
| **局域网查看 + 双口令 + 只读保护** | ❌ | ✅ | ✅（NEXT 在 LAN 版基础上开发）|
| **PixAI 新模型（30,877 标签 / 分级 / 作品 / 画风）** | ❌ | ❌ | ✅ |
| 建库速度 | 约 0.23 秒/张 | 同本地版 | **约 0.59 秒/张** |
| 特征维度 | 768 | 768 | 1024 |
